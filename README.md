# Portfólio Web

Portfólio profissional para apresentar projetos, serviços e o processo de trabalho de um desenvolvedor web freelancer.

## Destaques

- Apresentação profissional e responsiva
- Projetos de barbearia e pizzaria em destaque
- Pacotes para landing page, site institucional e sistema web
- Processo de trabalho em linha do tempo
- Seção sobre o profissional e diferenciais
- Mensagens comerciais específicas para cada serviço no WhatsApp
- Metadados para compartilhamento em redes sociais

## Tecnologias

- React 19
- TypeScript
- Vinext
- Vite
- Tailwind CSS
- Cloudflare Workers

## Executar no computador

```bash
npm install
npm run dev
```

## Validar o projeto

```bash
npm test
```

O teste gera a versão de produção e confirma que as principais seções do portfólio estão presentes.

## Configuração antes do uso comercial

Substitua `SEU NOME` e o número demonstrativo `5500000000000` pelos dados profissionais reais antes de divulgar o portfólio para clientes.
